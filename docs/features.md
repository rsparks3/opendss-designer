# Feature tour

## The palette

Click-and-place elements, each drawn with ANSI-style symbols:

- **Source** — an OpenDSS `Vsource` with short-circuit strength
- **Busbar** — stretchable, with connection points along the top and bottom
  edges; junction buses are created implicitly when you wire elements directly
  together
- **Transformer** — two-winding, with per-winding kV, connection (wye/delta),
  and impedance
- **Breaker / Switch** — double-click to open or close it
- **Load** — kW / pf, 1/2/3-phase, wye or delta, selectable load model
- **Capacitor** — shunt capacitor bank (kvar, steps)
- **Generator** — kW / pf with OpenDSS generator models

Placement is sticky (keep clicking to drop several, ++esc++ to stop), and every
palette item has a single-letter keyboard shortcut.

## Wires vs. Lines

Dragging between two terminals offers a choice:

- **Wire** — an ideal connection; the two terminals become the same OpenDSS
  bus (merged via union-find under the hood).
- **Line** — a real OpenDSS `Line` element with impedance and length.
  Conductor parameters can be filled from an editable preset library
  (`config/linecodes.csv`), or entered directly.

Illegal connections — busbar-to-busbar wires, self-connections, duplicates —
are refused with an explanation of why. Double-click any wire or line to add a
draggable routing point and shape the run; double-click a point to remove it.

## Live validation

The model is checked continuously as you draw: unconnected terminals, missing
source, islanded sections, duplicate names, and kV mismatches across
connections. Problems halo the offending element with a tooltip, and errors
disable Solve — so if Solve is clickable, the circuit is well-formed.

## Solving and results

**Solve** runs a snapshot power flow through OpenDSSDirect.py — the actual
OpenDSS engine, not a reimplementation. Results land directly on the diagram:

- per-unit bus voltages at every busbar,
- element loading as pie charts + percentages, and power flows,
- color-coded violations (undervoltage blue, overvoltage/overload red),
- total losses in the status bar.

**Auto** mode re-solves after every circuit change. The **Graph** tab plots
solved quantities with pick-your-axes controls — voltage profiles along the
feeder, in the classic OpenDSS plot style, with a resizable panel.

## Spreadsheet view

The **Elements** tab lists every source, busbar, transformer, line, breaker,
load, capacitor, and generator in an editable table — edit values in bulk with
an Excel-style fill-down handle, and click ⌖ to locate any element on the
diagram. After a solve, a read-only bus-results table appears alongside it.

## Files

- **Save / Open** — the whole project as a `.oneline.json` file (diagram
  geometry + all OpenDSS parameters).
- **Export** — a runnable `.dss` script, generated by the same compiler that
  feeds the solver, so what you export is exactly what was solved.
- **Import** — existing `.dss` models, including `redirect`ed files, with
  automatic hierarchical layout. See [Importing DSS files](importing-dss.md).

## Editor quality of life

Undo/redo, copy/paste, delete, rotation, grid snapping, pan/zoom with minimap,
box-select and group-move, right-click context menus, and tooltips throughout.
