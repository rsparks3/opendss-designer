OpenDSS Designer

A free, open-source graphical interface for OpenDSS. Draw a substation or feeder one-line diagram in your browser, press Solve, and read bus voltages, element loading and violations straight off the drawing. Every solve runs the real OpenDSS engine; the diagram is the model.

Import existing .dss files, run daily or yearly time-series simulations with load, solar and storage shapes, and export a runnable .dss script. Runs on Windows, macOS and Linux with pip install opendss-designer, or right here with nothing to install.

This page needs JavaScript to run the designer.
